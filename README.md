# 证据脑 EvidenceBrain

方向跟证据，盘口只对照。

这是按 2026-09-26 最终补丁（第 1 至 62 条）从源码重建的版本，不再往压缩包里手贴代码。

## 它能为你做什么

- 按销售日和开球时间自动算每场封盘时点（开球前 30 分钟与当日 21:45 / 22:45 取早）
- 从球探公开页抓平博亚盘、大小球、欧赔（公司编号 47 / 177），保留全部线，按「公司 + 数值线」建走势
- 从 FotMob 公开接口读伤停、首发、积分榜、赛程；英超可试 FPL；Transfermarkt 403 只记「扒不到」
- 体彩赔率只收你在浏览器里导入的 JSON，服务器不写代理、不借号
- 用 Dixon–Coles + 四分之一球通用公式，把平博全部线一起反推两队 μ，并与平博欧赔去水价对表
- 结论分成：有偏离 / 弱倾向 / 确实无偏离 / 盘外数据未接入；「倾向」和「可下」分开
- 每场有广实推论：九档由中游锚定再开盘反推，打分只用进失球/排名/近况，对照体彩欧赔和平博五五开亚盘，判实力、资金或诱盘；**不改盘口 μ**
- 手机优先界面，Safari 打开即可用；可加到 iPhone 主屏幕

## 本地运行

```bash
npm install
npm test
npm run build
npm start
```

开发时也可以：

```bash
npm run dev
```

默认 http://127.0.0.1:8787

导入体彩示例：`scripts/sample-import.json`，必须带 `businessDate`。

## 部署

这是普通的 Node + 静态网页。可以部署到任何能跑 `npm run build && npm start` 的主机（自己的 VPS、Render、Fly.io 等）。

**iPhone**

- 用 Safari 打开部署后的网址就能用
- 分享 → 添加到主屏幕，即 PWA，不必上架 App Store
- 正式上架 App Store 需要你自己的 Apple 开发者账号；Cursor 能写代码，不能替你提审、也不能把 App 装进你的手机

## 不做的事

- 不绕体彩 IP 封锁，不登录别人的账号，不破付费墙
- 不高频刷球探 / FotMob，频率跟着每场 `close_at`
- 缺格式的赔率直接报错，不按数字大小猜香港盘还是小数盘

计算源码在 `src/calc/`。当前算法哈希可用 `npm run hash` 查看，应不再是旧线上的 `3173b231…`。
